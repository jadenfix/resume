# Resume Studio

A local configurable resume builder. Python standard library only.

```sh
python app.py
# http://127.0.0.1:8083
python -m unittest -v test_e2e.py
```

Enter your own name, headline, contact information, experience and skills. Save to SQLite, inspect the sandboxed preview, then download safely escaped printable HTML. Open the exported file and print to PDF using your browser. No sample personal claims, resume scoring, ATS compatibility claims, remote storage or public hosting are implied. This unauthenticated workspace binds only to loopback. `--db` and `--port` configure storage/listening.
